This repository contains High-Level Design (HLD) sketches and Excalidraw diagrams for common system design problems.

The following systems are already explored in the Excalidraw files in this folder:

- WhatsApp / Chat System
- Rate Limiter
- Uber / Ride Hailing
- Dropbox / Google Drive
- Ticket Master / BookMyShow

## Goal

Practice and improve system design thinking by covering:

- functional requirements
- non-functional requirements
- bottlenecks and trade-offs
- core entities
- APIs and interfaces
- scalability considerations
- architecture choices

## Notes

This is meant to be an iterative learning log. Each design can be refined over time as understanding improves.
